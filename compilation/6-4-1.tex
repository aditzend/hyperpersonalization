\subsection{Proyección de costos}

\subsubsection{Desarrollo del sistema}

A continuación se desglosan las tareas necesarias para el desarrollo de cada componente y se estima el costo con base en la complejidad y el perfil de los desarrolladores requeridos.

Se toma un costo de USD 50 para los perfiles Sr. y USD 40 Jr.

\paragraph{Endpoint de generación de contexto hiperpersonalizado}

Este es el componente principal que usarán los clientes para mejorar las respuestas de sus bots.

Tareas:
\begin{itemize}
    \item Diseño y desarrollo del endpoint (Sr.): 40 horas.
    \item Implementación de lógica de generación de contexto (Sr.): 60 horas.
    \item Pruebas y optimización (Sr.): 20 horas.
\end{itemize}

\paragraph{Módulo agencial de consulta de información personal}

Funciona en segundo plano y garantiza consultas seguras de fuentes privadas.

Tareas:
\begin{itemize}
    \item Diseño del sistema agencial (Sr.): 50 horas.
    \item Desarrollo de la lógica de consulta segura (Sr.): 80 horas.
    \item Pruebas de seguridad y optimización (Sr.): 30 horas.
\end{itemize}

\paragraph{Conectores a bases de datos más difundidas}

Incluye conectores para MySQL, SQL Server, MongoDB y Oracle.

Tareas:
\begin{itemize}
    \item Desarrollo de conectores para cada base de datos:
    \begin{itemize}
        \item MySQL y SQL Server (Jr.): 40 horas cada uno.
        \item MongoDB y Oracle (Sr.): 40 horas cada uno.
    \end{itemize}
    \item Pruebas de integración y optimización (Sr.): 20 horas.
\end{itemize}

\paragraph{Conectores a CRMs y ERPs más conocidos}

Incluye conectores para SalesForce y SAP.

Tareas:
\begin{itemize}
    \item Desarrollo de conectores para SalesForce y SAP (Sr.): 60 horas cada uno.
    \item Pruebas de integración (Sr.): 20 horas.
\end{itemize}

\paragraph{Módulo de configuración con interfaz gráfica}

Permite a los clientes configurar el sistema mediante una interfaz intuitiva.

Tareas:
\begin{itemize}
    \item Diseño y desarrollo de la interfaz gráfica (Sr.): 80 horas.
    \item Implementación de la lógica de configuración (Sr.): 60 horas.
    \item Pruebas de usuario (Jr.): 20 horas.
\end{itemize}

\paragraph{Contador de uso}

Monitorea el consumo de tokens para interpretar información y generar respuestas.

Tareas:
\begin{itemize}
    \item Desarrollo del sistema de conteo de tokens (Sr.): 40 horas.
    \item Pruebas de precisión y optimización (Sr.): 20 horas.
\end{itemize}
