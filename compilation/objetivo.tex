\section{Objetivos e hipótesis}

\subsection{Hipótesis}

A partir del análisis de interacciones previas entre un usuario y un sistema informático, así como de las conversaciones sostenidas entre el usuario y un asistente virtual, es posible construir una base de datos híbrida — que combine componentes semánticos y estructurados — de la información personal del usuario. Dicha base de datos podría ser consultada posteriormente para aportar contexto relevante en la generación de respuestas por parte del asistente virtual.

El tema fundamental de la privacidad de los datos personales no es objeto de este trabajo desde el punto de vista técnico, ya que el foco está puesto en la funcionalidad y la precisión de la hiperpersonalización. No obstante, el plan de negocio desarrollado en los apéndices incorpora un marco de cumplimiento normativo y gestión de riesgos de datos —incluyendo la Ley~25.326 de Protección de Datos Personales, acuerdos de tratamiento de datos y controles de prevención de fugas— como condición necesaria para la viabilidad comercial de la solución propuesta.

\subsection{Objetivos}

Se plantea como objetivo principal encontrar una solución tan simple, económica y eficiente como sea posible para la construcción de sistemas conversacionales que permitan la hiperpersonalización de las interacciones con los usuarios. Desde la perspectiva de las tecnologías aplicadas, es preferible hallar una solución subóptima con las herramientas que se encuentran en uso actualmente que una solución óptima con tecnologías difíciles de integrar, agregando complejidad al mantenimiento de todo el sistema.

Para alcanzar este objetivo general se plantean los siguientes objetivos específicos:

\begin{enumerate}
    \item Diseñar una arquitectura de ingestión, almacenamiento y recuperación de información personal basada en \textit{embeddings} y búsqueda por similitud vectorial.
    \item Explorar y contrastar distintas tecnologías de base de datos —un esquema en memoria con caché de mensajes y búsqueda vectorial (Redis y FAISS), una base de grafos y una base documental con soporte vectorial— y seleccionar la más adecuada para soportar dicha arquitectura.
    \item Construir conjuntos de datos sintéticos de alcance anual sobre una persona y validar, mediante casos de uso, la recuperación de contexto relevante.
    \item Identificar y caracterizar las limitaciones del enfoque propuesto y delinear los componentes necesarios para una implementación productiva.
\end{enumerate}
